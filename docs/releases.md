# Custom firmware releases

Custom firmware for the **Pioneer XDJ-RX** (the original model), built on Pioneer's official
firmware. Each release lists its features, settings and how to install it.

| Release | Based on | Highlights | Release notes |
|---|---|---|---|
| **3.00** (latest) | official 2.21 | exFAT USB sticks, FLAC, 60 fps screen, colour waveforms, hot cues A–H in colour (E–H on the pads), beat jump, smooth scrolling | [release notes](release-notes-3.00.md) |

> Unofficial and not affiliated with Pioneer DJ / AlphaTheta. Install at your own risk.

To install any release you need Pioneer's official XDJ-RX firmware 2.21 (from Pioneer's
website), the release's patch file, the **xdjrx-patcher** for your computer (Windows, Mac or
Linux) and a USB stick formatted as **FAT32**. The patcher turns the official firmware into the
release on your computer and checks the result; each release's notes have the step-by-step
guide.

Downloads per release: `xdjrx-<release>.xdjpatch`, `xdjrx-patcher-windows-x86_64.exe`,
`xdjrx-patcher-macos`, `xdjrx-patcher-linux-x86_64`.
